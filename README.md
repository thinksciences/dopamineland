# Dopamine Land

An interactive three.js candy world built to be a feast for the senses: a glowing blob that keeps changing shape, wobbly glossy candy shapes, confetti, glitter and music generated live in the browser.

## Run

```bash
python3 -m http.server 5173
```

Then open http://localhost:5173 and click **Enter** (sound on).

## Play

- **Click shapes** to pop them. Pop quickly in a row to build a combo of rising notes.
- **Tap the blob** for a chord. **Hold it** to charge, then release to make it explode.
- **Space** triggers a DOPAMINE RUSH. **Letter keys** pop shapes and play notes.
- Fill the rush meter to set off a rush automatically.
